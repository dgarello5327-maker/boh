# NeonWave Music

App Android di musica con interfaccia nera e viola neon, riproduzione di file audio locali e streaming da Internet Archive. Include playlist, preferiti, ricerca, controlli multimediali e build APK tramite GitHub Actions.

## Build APK
Apri la scheda **Actions**, avvia il workflow **Build Android APK** e scarica l'artifact `NeonWave-debug-apk` al termine della build.

## Nota
Il progetto è in sviluppo: l'APK deve superare la build e un test su dispositivo prima di essere considerato verificato.
